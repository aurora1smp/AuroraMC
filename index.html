O que é a AuroHost?

É um Host de Minecraft com configuração e gerenciamento inclusos. Mais simples, prática e acessível.

  • Configuração inicial do servidor
  • Preparação para você entrar e jogar
  • Gerenciamento do mapa

  • Liberdade para criar, explorar e reunir jogadores

Planos

Os valores são mensais. O plano já define jogadores, RAM e CPU. O servidor fica pronto em até 48h após o pagamento.

Perguntas frequentes

O que é a AuroHost?
É um Host de Minecraft com configuração e gerenciamento inclusos.
O que está incluso no Host?
Configuração inicial, preparação do servidor, gerenciamento do mapa e suporte técnico e de console.
Quanto tempo demora para o servidor ficar pronto?
Até 48h após a confirmação do pagamento.
Quanto custa?
Como o plano é escolhido?
Você escolhe em Planos, e ele já define os recursos. O Básico é o menor: 4 jogadores, 3 GB de RAM e CPU Padrão. O Pro tem jogadores e RAM ilimitados, o Avançado soma CPU Avançada e o Premium tem CPU Extrema.
Qual a diferença entre as CPUs?
A Padrão atende bem grupos de amigos. A Avançada dá mais desempenho para mais jogadores e addons. A Extrema é a mais potente.
Como envio meu mapa?
Escolha "Usar meu mapa" no pedido. Depois de confirmar, o suporte entra em contato para coletar o arquivo do mundo.
Como peço addons?
Escolha "Com addons" no pedido. Depois de confirmar, o suporte entra em contato para coletar os addons que você quer.
Posso mudar de plano depois?
Sim. Comece com poucos jogadores e mude de plano quando o servidor encher.
O que é a whitelist?
É a lista de jogadores autorizados. Com ela ativada, só entra quem você liberar.
O que são cheats?
São comandos como /gamemode e /time. Com cheats ativados, quem tem permissão pode usá-los.

Perguntas frequentes

Quanto custa?
Região Padrão, R$ 4,99: 0,20 km² ou 3 km². Região Plus, R$ 6,70: 20 km². Região Premium, R$ 9,99: 50 km² ou 100 km².
Quando meu mapa começa a ser feito?
Somente depois que o pagamento for confirmado. Sem pagamento, o mapa não é gerado.
Quanto tempo demora?
Depois da confirmação do pagamento, o mapa fica pronto em até 7 dias e é enviado pelos contatos informados no pedido.
O que é o spawn?
É o ponto onde você nasce no mapa. Aqui ele é o endereço que você informar, que também fica no centro da área.
De onde vêm os dados do mapa?
O Arnis usa o OpenStreetMap para edifícios, estradas e uso do solo, via API Overpass. Elevação e terreno vêm do AWS Terrain Tiles.
Por que o mapa pode ter menos detalhes em alguns lugares?
Os dados do OSM são feitos pela comunidade, então a cobertura varia. Cidades bem mapeadas geram mundos mais detalhados; regiões rurais podem ter dados incompletos.
O mapa vai ficar idêntico ao lugar real?
Não exatamente. A geração é automática a partir de dados públicos: lugares bem mapeados ficam excelentes e os com menos dados geram construções mais genéricas. O software ainda está em desenvolvimento.
Por que pedem nome, data de nascimento e e-mail?
O nome identifica o pedido, o e-mail é o destino da entrega e a data de nascimento nos ajuda a atender cada pessoa. Usamos os dados apenas para este pedido.
